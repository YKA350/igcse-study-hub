3Family pedigrees
Reading a pedigree

Key

Square male, circle female. Filled = affected. Horizontal line: parents. Vertical line: children.

Clue

Two unaffected parents, affected child: both are carriers (Ff). Next child affected: 1 in 4.

5Variation
Causes of variation

Genetic

Different alleles: blood group, cystic fibrosis.

Environmental

Diet, climate, sunlight, scars, accent.

Both

Height, weight, skin colour: genes set the potential.

Continuous vs discontinuous

Continuous

Any value in a range; many genes plus environment.

Discontinuous

Distinct categories; one gene.

Polygenic inheritance and twins

Polygenic

Many genes act together: height, skin colour, body mass.

Common mistakeMost features are polygenic, not single-gene.

Identical twins

Same genes, so differences come from the environment.

Exam tipTwins raised apart show genes vs environment.

✓ Say this

Dominant: expressed with one or two copies. Recessive: only when homozygous. Parents must be heterozygous carriers.

✗ Avoid this

Mixing up genotype and phenotype; forgetting gametes; 'previous children affect the next'.
