Truth table

Boolean

Something that can take only the values True or False. Named after George Boole.

Logic circuit

An electronic circuit whose inputs and outputs follow a Boolean operator. AND, OR and NOT are easy to build as logic circuits.

Writing logic statements (1/3)

  1. Work out the important features in the rules. These become your variables.
  2. Start with a default, e.g. SET advice TO nothing needed, and change only if conditions are met.
  3. Mistakes in logic (logic errors) are a frequent cause of bugs. Check the code matches the logic.
SET advice TO 'nothing needed'
IF colour = 'yellow' THEN
  SET advice TO 'nitrogen'
ELSE IF colour = 'brown' AND size = 'small' THEN
  SET advice TO 'phosphorous'
ELSE IF colour = 'brown' AND size = 'normal' THEN
  SET advice TO 'potassium'
END IF
