Truth table

A table showing all possible combinations of inputs and the output of a logic statement.

Boolean

Something that can take only the values True or False. Named after George Boole.

Logic circuit

An electronic circuit whose inputs and outputs follow a Boolean operator. AND, OR and NOT are easy to build as logic circuits.

Conditions and truth tables (4/6)

Exam tip Operator precedence is the order operators are applied: brackets first, then NOT, then AND, then OR.

AND Output is true only if both conditions are true.

OR Output is true if either condition (or both) is true, e.g. health <= 0 OR score > 1000000.

Writing logic statements

Writing logic statements (1/2)

Work out the important features in the rules. These become your variables.

Start with a default, e.g. SET advice TO nothing needed, and change only if conditions are met.

Mistakes in logic (logic errors) are a frequent cause of bugs. Check the code matches the logic.
