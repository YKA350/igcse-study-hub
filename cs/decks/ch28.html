Intellectual property

Intellectual property (1/3)

Intellectual property (IP)

A unique creation of the human mind that has commercial value, such as software, a game, a processor design, an image, music or writing. Not the same as an IP address.

  1. The Copyright, Designs and Patents Act makes it illegal to copy, modify or distribute IP without permission.
  2. Downloading software without paying is illegal and unethical because the programmer is not paid.
  3. The creators of The Pirate Bay were jailed and fined over US$4 000 000.

Intellectual property (2/3)

Copyright

Protects the expression of an idea, e.g. source code, not the idea itself. Someone else can write a program that does the same job unless you prove it was copied. The © symbol shows protection.

Patent

Gives the inventor the exclusive right to make, use and sell an invention for a fixed period, 20 years. Protects the idea or design, not only one form, so it is stronger than copyright. The invention must be distinct from anything existing.

Intellectual property (3/3)

  1. Patent wars, e.g. Apple v Samsung over the look and feel of the iPhone, may discourage imagination as money goes on lawsuits not inventions.
  2. Apple sued Microsoft over overlapping windows in Windows 2.0, which were not part of its 1994 licence.

Software licences

Software licences (1/2)

Software licence

A legal agreement stating how software may be used. The buyer does not own the software, the maker keeps ownership.

Spec 6.1.3 Understand the legal impact of using technology
Software licences

Software licences (2/2)

  1. A licence says how many copies you can use, whether you can install on more than one computer, what type of organisation can use it (charity, student, home), and how long (perpetual or expiring).
  2. You usually cannot resell it.
  3. Paid software often has a unique licence key proving it is genuine and preventing illegal copying.
  4. Free software also has a licence.
  5. A Creative Commons licence lets creators allow use of music, photos or software under set conditions, e.g. not commercially.

Open source and proprietary

Open source and proprietary

Open-source software

Freely available. Anyone may edit the code and pass it on without charging. Advantages: free, can be modified, shows programming ideas. Disadvantages: may be less user friendly, little or no support, criminals can find vulnerabilities in the open code. Python is open source.

Proprietary software

Belongs to a person or company, closed source. Users may not modify the code and use is restricted. Advantages: extensively tested, bugs fixed quickly, plenty of support. Disadvantage: cannot be changed. Examples: Windows 10, iTunes, Adobe Photoshop, macOS.

Computer Misuse Acts

Computer Misuse Acts

  1. Many countries (Europe, the GCC, Australia, Singapore) have Computer Misuse Acts.
  2. They make it illegal to access computer systems without permission, with higher penalties for deleting data or using information for fraud or data theft.
