Programs and algorithms (1/2)

Execution

The process by which a computer carries out the instructions of a program.

An algorithm is a precise method of solving a problem.

A program is an algorithm converted into program code so it can be executed.

A well-written algorithm is free of logic errors and easy to code in any high-level language.

Data types

The common types (1/2)

Integer

Description: Whole numbers with no fractional part; Examples: age = 30

Real or float

Description: Numbers with a decimal part; Examples: weight = 25.5, price = 12.55

Boolean

Description: Only two values: True or False; Examples: correct = False

Data types

The common types (2/2)

Character

Description: A single letter, symbol, number or space; Examples: gender = 'm'

String

Description: A set of characters treated as text; Examples: name = 'Catherine'

Exam tip Python has no character data type, so use a string of length one.
Data types

Declaring and choosing types (1/2)

Variables are named memory locations. They control loops, choose IF branches, keep running totals and hold user input.

In pseudocode declaring types is optional but a good idea, e.g. BOOLEAN correct, CHARACTER gender.

You can state the type in RECEIVE, e.g. RECEIVE age FROM (INTEGER) KEYBOARD.

Data types

Declaring and choosing types (2/2)

The data type decides which operations are possible: 8 * 5 = 40 for integers, 8.0 * 5 = 40.0 for reals, but '8' * 5 = '88888' for a character or string.

Python chooses the type automatically from the value. Java and C# need the type declared before use.

Data types

Variable initialisation (1/2)

Initialisation

Giving a variable its first value before it is used, because a new variable's memory location is empty.

Initialise when the program runs, e.g. SET total TO 0.

Or read the value from the keyboard, e.g. RECEIVE admissionCharge FROM (INTEGER) KEYBOARD.

Data types

Variable initialisation (2/2)

After that an assignment statement changes it, e.g. SET total TO total + admissionCharge.

Running totals and loop counters must start at a value. Some languages refuse to run otherwise and others give unexpected results.

Data types

Type coercion (1/2)

Type coercion

Converting the value in a variable from one data type to another.

If an integer and a real are used in an arithmetic operation, the result is always a real.

Python and Java do this automatically. C# calls it casting, implicit when automatic and explicit when you ask for it.

Data types

Type coercion (2/2)

A common explicit cast converts a string read from the keyboard into a number, e.g. int.Parse in C# or int(input(...)) in Python.

Selection

IF, THEN, ELSE (1/2)

The computer picks a branch from the outcome of a condition.

A standard IF … THEN … ELSE gives two alternatives.

For more than two, Edexcel pseudocode needs a nested IF: IF statements placed inside each other.

Selection

IF, THEN, ELSE (2/2)

Every IF must end with its own END IF at the correct indentation.

Python, Java and C# have else if (elif in Python) so nesting is not needed.

Logical operators (1/2)

Exam tip Python uses and, or, not. Java and C# use &&, || and !.

AND Both conditions must be true for the whole statement to be true.

OR At least one condition must be true.

Logical operators (2/2)

NOT Reverses the logic. IF NOT (A = 3 AND B = 6) is true when A and B are not both equal to those values.

Loops

Definite and indefinite

Definite iteration You know in advance how many times the loop runs, e.g. display a character for a fixed time.

Indefinite iteration The number of repeats is not known in advance, e.g. let a user play a game as many times as they like. It repeats until a condition is reached.

Loops

Definite loops in pseudocode

The STEP version outputs 0, 25, 50, 75, 100 because the loop includes the end value. The book's Python range(0,100,25) stops before 100, so use range(0,101,25) to include 100.

In Python, for x in range(6) gives 0 to 5, and range(2,6) gives 2 to 5.

A loop can step through a list

for colour in aList prints each item, and continue skips an item.

Loops

Nested loops (1/2)

A nested loop is a loop within a loop.

Each pass of the outer loop runs the inner loop to completion.

Example

for each of 20 students, an inner loop reads 5 marks, adds them to sum (initialised to 0) and the average is sum / 5.

Loops

Nested loops (2/2)

Use int(...) to convert the typed text to a number before adding.

Loops

Indefinite loops

Python, Java and C# use a while loop

something is done while a condition is met.

Example

keep asking for numbers while the number is less than or equal to 20, then print a message when it is greater.

Make sure something inside the loop changes the condition or it never ends.
