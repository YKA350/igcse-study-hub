Programs and algorithms

Programs and algorithms

  1. An algorithm is a precise method of solving a problem.
  2. A program is an algorithm converted into program code so it can be executed.
  3. A well-written algorithm is free of logic errors and easy to code in any high-level language.
  4. High-level languages read like human language but need a translator to become machine code.
  5. Examples in the book are in Pearson Edexcel pseudocode, Python, Java and C#.
Execution

The process by which a computer carries out the instructions of a program.

Data types

Declaring and choosing types

  1. Variables are named memory locations. They control loops, choose IF branches, keep running totals and hold user input.
  2. In pseudocode declaring types is optional but a good idea, e.g. BOOLEAN correct, CHARACTER gender.
  3. You can state the type in RECEIVE, e.g. RECEIVE age FROM (INTEGER) KEYBOARD.
  4. The data type decides which operations are possible: 8 * 5 = 40 for integers, 8.0 * 5 = 40.0 for reals, but '8' * 5 = '88888' for a character or string.
  5. Python chooses the type automatically from the value. Java and C# need the type declared before use.

Variable initialisation

Initialisation

Giving a variable its first value before it is used, because a new variable's memory location is empty.

  1. Initialise when the program runs, e.g. SET total TO 0.
  2. Or read the value from the keyboard, e.g. RECEIVE admissionCharge FROM (INTEGER) KEYBOARD.
  3. After that an assignment statement changes it, e.g. SET total TO total + admissionCharge.
  4. Running totals and loop counters must start at a value. Some languages refuse to run otherwise and others give unexpected results.

Type coercion (1/2)

Type coercion

Converting the value in a variable from one data type to another.

  1. If an integer and a real are used in an arithmetic operation, the result is always a real.
  2. Python and Java do this automatically. C# calls it casting, implicit when automatic and explicit when you ask for it.
  3. A common explicit cast converts a string read from the keyboard into a number, e.g. int.Parse in C# or int(input(...)) in Python.

Selection

IF, THEN, ELSE (1/2)

IF day = 'Saturday' OR day = 'Sunday' THEN
  SET alarm TO 11
ELSE
  SET alarm TO 8
END IF
  1. The computer picks a branch from the outcome of a condition.
  2. A standard IF … THEN … ELSE gives two alternatives.
  3. For more than two, Edexcel pseudocode needs a nested IF: IF statements placed inside each other.
  4. Every IF must end with its own END IF at the correct indentation.
  5. Python, Java and C# have else if (elif in Python) so nesting is not needed.

Logical operators

AND

Both conditions must be true for the whole statement to be true.

OR

At least one condition must be true.

NOT

Reverses the logic. IF NOT (A = 3 AND B = 6) is true when A and B are not both equal to those values.

Exam tipPython uses and, or, not. Java and C# use &&, || and !.

Loops

Definite and indefinite

Definite iteration

You know in advance how many times the loop runs, e.g. display a character for a fixed time.

Indefinite iteration

The number of repeats is not known in advance, e.g. let a user play a game as many times as they like. It repeats until a condition is reached.

Spec 2.2.2 Be able to use sequencing, selection and iteration constructs in their programs
Loops

Definite loops in pseudocode

REPEAT 50 TIMES
  SEND '*' TO DISPLAY
END REPEAT
FOR times FROM 1 TO 100 DO
  SEND '*' TO DISPLAY
END FOR
FOR times FROM 0 TO 100 STEP 25 DO
  SEND times TO DISPLAY
END FOR
  1. The STEP version outputs 0, 25, 50, 75, 100 because the loop includes the end value. The book's Python range(0,100,25) stops before 100, so use range(0,101,25) to include 100.
  2. In Python, for x in range(6) gives 0 to 5, and range(2,6) gives 2 to 5.
  3. A loop can step through a list: for colour in aList prints each item, and continue skips an item.

Loops

Nested loops

  1. A nested loop is a loop within a loop.
  2. Each pass of the outer loop runs the inner loop to completion.
  3. Example: for each of 20 students, an inner loop reads 5 marks, adds them to sum (initialised to 0) and the average is sum / 5.
  4. Use int(...) to convert the typed text to a number before adding.

Loops

Indefinite loops

SET counter TO 10
WHILE counter > 0 DO
  SEND counter TO DISPLAY
  SET counter TO counter - 1
END WHILE
  1. Python, Java and C# use a while loop: something is done while a condition is met.
  2. Example: keep asking for numbers while the number is less than or equal to 20, then print a message when it is greater.
  3. Make sure something inside the loop changes the condition or it never ends.
