Why networks

Why networks

Why networks (1/2)

Network

An arrangement of computers and other devices connected together to share resources and data.

Server

A powerful computer that provides services such as file storage or email. A small network may have one server, a large business tens or hundreds.

Users can store personal files on a central server, which gives extra space and back-up.

Why networks

Why networks (2/2)

Share files with others.

Download data and updates.

Send work to a shared printer.

Access the Internet.

Communicate by email, video or games.

Types of network

Networks

Types of network

Types of network (1/2)

LAN Local area network. Covers a small area such as a home, hospital or factory. The hardware is usually owned by the organisation.

WLAN A LAN that uses high-frequency radio waves, e.g. a wireless router at home.

WAN Wide area network. Connects two or more LANs across a large area, usually owned by shared organisations. The Internet is the largest WAN.

Types of network

Types of network (2/2)

PAN Personal area network. Devices such as phones, laptops, speakers and printers over about 10 metres, usually using Bluetooth.

Client-server and peer-to-peer

Networks

Client-server and peer-to-peer

Client-server and peer-to-peer (1/3)

Client-server network

A network with at least one server giving services to client computers. The server authenticates users and gives access to permitted files.

Peer-to-peer network

A network with no dedicated servers. Every computer can act as both client and server and share files or printers.

Client-server and peer-to-peer

Client-server and peer-to-peer (2/3)

Client makes a connection using the server's address.

It then sends a service request.

If valid, the server sends the data back to the client's address.

Example

a web browser logging in to web-based email.

Client-server and peer-to-peer

Client-server and peer-to-peer (3/3)

Some instant messengers use peer-to-peer so messages go directly to the recipient.

Internet P2P file sharing is used for pirated media because no records are kept, but also for legal downloads such as some Linux versions.

Network topologies

Networks

Network topologies

Network topologies (1/3)

Network topology

How the devices on a network are connected.

Bus One cable with terminators at each end that absorb signals. Only one message at a time, so CSMA/CD handles collisions.

Cheap and easy to extend but fails if the cable is cut, gets slower with more devices, and all devices see all data. Used in cars (CAN bus).

Network topologies

Network topologies (2/3)

Ring Devices in a closed loop, data travels one direction, no collisions. Adding devices does not slow it, but the network fails if the cable or a device fails, adding a device needs shutdown, and more cable is needed.

Star Every device connects to a central hub or switch. The most widely used. One cable fault affects only that device and faults are easy to find.

A switch sends messages only to the device needing them. Needs lots of cable and fails entirely if the hub or switch fails.

Network topologies

Network topologies (3/3)

Mesh Devices connected to many others. Fully connected: every device to every other. Very fault tolerant because messages are re-routed. Wired mesh is expensive and hard to manage.

Wireless mesh extends range. The Internet is the largest mesh. Used for IoT sensors.

Network topologies

CSMA/CD (1/2)

Check if the bus is busy.

If not, send the message, otherwise go back to step 1.

Listen to see if it arrived correctly.

If not, wait any amount of time, then retry.

Network topologies

CSMA/CD (2/2)

A random wait stops senders colliding repeatedly.

A collision is when two devices send together and the messages become unreadable.

Communication media

Communication media (1/2)

Faster

No cables, more flexible

Hard to eavesdrop on

Can be slower and affected by interference and walls

Less interference

Allows many devices and own devices

Expensive to install and reconfigure

Data must be encrypted to stop eavesdropping

Communication media

Communication media (2/2)

Wired

physical connection, mostly copper wire (electrical signals) or fibre-optic cable (glass or plastic, light signals). Fibre is faster and travels further.

Wireless

radio signals, or infra-red over short distances. Methods include mobile networks, Bluetooth and Wi-Fi.

ZigBee is an open-source low-power protocol for controlling devices.

Network speed

Networks

Network speed

Network speed

Bandwidth

The amount of data that can be sent in a given time, in bits per second (bps).

Latency

The delay data meets travelling through a network. Low latency means small delays.

Exam tip Storage uses bytes but network speed uses bits per second. Do not confuse them.

Protocols

Networks

Protocols

Protocols (1/4)

Protocol

A set of rules governing how communications between devices are formatted, sent and received.

SMTP Simple Mail Transfer Protocol. Sends email.

POP3 Post Office Protocol 3. Retrieves email, normally downloading and deleting it from the server.

IMAP Internet Message Access Protocol. Accesses email from several clients and leaves messages on the server.

Protocols

Protocols (2/4)

Ethernet A family of protocols for wired LANs covering cables, connectors, error checking and speed.

Wi-Fi A digital protocol for wireless LANs.

TCP Gives a reliable connection using acknowledgements, checksums, flow control and removal of duplicates. Used for web pages, email and file transfer.

Protocols

Protocols (3/4)

A checksum is a number from a formula applied to the data. If the receiver's number differs, the data is corrupted and is requested again.

HTTP and HTTPS HTTP carries web pages between browsers and servers, e.g. a 404 error if a page is missing. HTTPS encrypts the data and helps confirm the real server.

FTP File Transfer Protocol. Moves files over TCP networks, e.g. uploading web pages to a server.

Protocols

Protocols (4/4)

A protocol can cover addressing, routing, error checking, acknowledgement, what to do if data fails, formatting, sequencing and synchronising speeds.

Without common protocols devices could not talk to each other.

Protocols

The TCP/IP stack (1/3)

Application

Interacts with the user, e.g. HTTP, FTP, email

Transport

End-to-end communication, e.g. TCP

Internet

Routing across networks, uses IP addresses

Protocols

The TCP/IP stack (2/3)

Link

Sends and receives data on the local network

Data goes down the layers on the sending computer and up on the receiving one.

Data is split into packets. Each has a header with sender, recipient, number of packets and its position.

Protocols

The TCP/IP stack (3/3)

The receiver rebuilds the data. A network of this type is packet switched.

IP gives each device a unique address and adds source and destination addresses.

UDP is another transport protocol.
