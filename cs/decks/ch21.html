Why networks (1/2)

Network

An arrangement of computers and other devices connected together to share resources and data.

Server

A powerful computer that provides services such as file storage or email. A small network may have one server, a large business tens or hundreds.

Types of network

Types of network

Types of network

LAN

Local area network. Covers a small area such as a home, hospital or factory. The hardware is usually owned by the organisation.

WLAN

A LAN that uses high-frequency radio waves, e.g. a wireless router at home.

WAN

Wide area network. Connects two or more LANs across a large area, usually owned by shared organisations. The Internet is the largest WAN.

PAN

Personal area network. Devices such as phones, laptops, speakers and printers over about 10 metres, usually using Bluetooth.

Client-server and peer-to-peer

Client-server and peer-to-peer (1/2)

Client-server network

A network with at least one server giving services to client computers. The server authenticates users and gives access to permitted files.

  1. Client makes a connection using the server's address.
  2. It then sends a service request.
  3. If valid, the server sends the data back to the client's address.
  4. Example: a web browser logging in to web-based email.

Client-server and peer-to-peer (2/2)

Peer-to-peer network

A network with no dedicated servers. Every computer can act as both client and server and share files or printers.

  1. Some instant messengers use peer-to-peer so messages go directly to the recipient.
  2. Internet P2P file sharing is used for pirated media because no records are kept, but also for legal downloads such as some Linux versions.

Network topologies

Network topologies (2/3)

Bus

One cable with terminators at each end that absorb signals. Only one message at a time, so CSMA/CD handles collisions. Cheap and easy to extend but fails if the cable is cut, gets slower with more devices, and all devices see all data. Used in cars (CAN bus).

Ring

Devices in a closed loop, data travels one direction, no collisions. Adding devices does not slow it, but the network fails if the cable or a device fails, adding a device needs shutdown, and more cable is needed.

Network topologies

Network topologies (3/3)

Star

Every device connects to a central hub or switch. The most widely used. One cable fault affects only that device and faults are easy to find. A switch sends messages only to the device needing them. Needs lots of cable and fails entirely if the hub or switch fails.

Mesh

Devices connected to many others. Fully connected: every device to every other. Very fault tolerant because messages are re-routed. Wired mesh is expensive and hard to manage. Wireless mesh extends range. The Internet is the largest mesh. Used for IoT sensors.

Network topologies

Star

Each device links to a central switch. One cable failing affects one device, but the switch is a single point of failure.

Bus and ring

Devices share one cable or a loop. Cheap, but one break can stop the network.

Mesh

Devices link to many others, so data can take another route if one fails.

Network topologies

CSMA/CD

  1. Check if the bus is busy.
  2. If not, send the message, otherwise go back to step 1.
  3. Listen to see if it arrived correctly.
  4. If not, wait any amount of time, then retry.
  5. A random wait stops senders colliding repeatedly.
  6. A collision is when two devices send together and the messages become unreadable.

Communication media

Communication media (1/2)

  1. Wired: physical connection, mostly copper wire (electrical signals) or fibre-optic cable (glass or plastic, light signals). Fibre is faster and travels further.
  2. Wireless: radio signals, or infra-red over short distances. Methods include mobile networks, Bluetooth and Wi-Fi.
  3. ZigBee is an open-source low-power protocol for controlling devices.

Protocols

Protocols (1/4)

Protocol

A set of rules governing how communications between devices are formatted, sent and received.

  1. A protocol can cover addressing, routing, error checking, acknowledgement, what to do if data fails, formatting, sequencing and synchronising speeds.
  2. Without common protocols devices could not talk to each other.

Protocols

Protocols (2/4)

SMTP

Simple Mail Transfer Protocol. Sends email.

POP3

Post Office Protocol 3. Retrieves email, normally downloading and deleting it from the server.

IMAP

Internet Message Access Protocol. Accesses email from several clients and leaves messages on the server.

Ethernet

A family of protocols for wired LANs covering cables, connectors, error checking and speed.

Protocols (3/4)

Wi-Fi

A digital protocol for wireless LANs.

TCP

Gives a reliable connection using acknowledgements, checksums, flow control and removal of duplicates. Used for web pages, email and file transfer. A checksum is a number from a formula applied to the data. If the receiver's number differs, the data is corrupted and is requested again.

Protocols (4/4)

HTTP and HTTPS

HTTP carries web pages between browsers and servers, e.g. a 404 error if a page is missing. HTTPS encrypts the data and helps confirm the real server.

FTP

File Transfer Protocol. Moves files over TCP networks, e.g. uploading web pages to a server.

The TCP/IP stack (2/2)

  1. Data goes down the layers on the sending computer and up on the receiving one.
  2. Data is split into packets. Each has a header with sender, recipient, number of packets and its position.
  3. The receiver rebuilds the data. A network of this type is packet switched.
  4. IP gives each device a unique address and adds source and destination addresses.
  5. UDP is another transport protocol.

The 4-layer TCP/IP model

Layers

Packets

Why layers
