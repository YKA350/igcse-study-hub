This chapter in a nutshell

Storage is measured in bits, nibbles, bytes and larger units with decimal (kilo, mega) or binary (kibi, mebi) prefixes.

Compression makes files smaller.

Lossless keeps all data, e.g. run-length encoding.

Lossy removes some data permanently, e.g. JPEG and MP3.

Data storage and compression

Compression

Compression

  1. Compression reduces file size so files take less storage and transfer faster.
  2. It is used for images, audio, video and documents.

Lossless compression

None of the data is lost. The original can be rebuilt exactly. Used for text, programs and some images, e.g. PNG and ZIP.

Lossy compression

Some data is permanently lost. Gives much smaller files. Used for photos, music and video, e.g. JPEG and MP3.

Run-length encoding

How it works

Runs of the same value are stored once, with a count.

Lossless

No data is lost, so the file decompresses back exactly.

Best for

Data with long runs, like simple images. It can make random data bigger.

Compressing images and audio

  1. Bitmap images can be compressed by reducing colour depth or resolution (lossy) or by run-length encoding (lossless).
  2. Audio can be compressed by lowering the sample rate or bit depth (lossy) or by lossless methods.
