Compression

Data storage and compression

Compression

Compression (1/2)

Lossless compression None of the data is lost. The original can be rebuilt exactly. Used for text, programs and some images, e.g. PNG and ZIP.

Lossy compression Some data is permanently lost. Gives much smaller files. Used for photos, music and video, e.g. JPEG and MP3.

Compression

Compression (2/2)

Compression reduces file size so files take less storage and transfer faster.

It is used for images, audio, video and documents.

Compression

Run-length encoding

Run-length encoding (RLE)

A lossless method that replaces a run of the same value with the value and a count.

RLE works best when there are long runs of the same data, e.g. a plain background.

It may make a file bigger if few values repeat.

Compression

Compressing images and audio

Exam tip In the exam say how much the file shrinks and what is lost.

Bitmap images can be compressed by reducing colour depth or resolution (lossy) or by run-length encoding (lossless).

Audio can be compressed by lowering the sample rate or bit depth (lossy) or by lossless methods.
