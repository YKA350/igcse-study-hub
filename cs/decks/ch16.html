Input, process, output

Input, process, output (1/4)

Input

Data entered into a computer system.

Process

To change the meaning or format of data by following rules.

Output

Processed or stored data displayed or sent out.

Input, process, output

Input, process, output (2/4)

Function machine

A diagram or metaphor of a machine that takes an input, applies a rule and delivers an answer.

A computer takes input from its surroundings, processes it by given rules and gives output.

Embedded computers are fixed inside other objects, e.g. a washing machine: controls are inputs, the motor and heater are outputs.

Input, process, output (3/4)

Desktop

keyboard and mouse in, screen out.

Processing follows an algorithm, a precise step-by-step method.

Anything beyond the simplest algorithm needs temporary storage (memory) to keep track of working.

Flowchart symbols

Computational models

Computational models (1/2)

Sequential Instructions are followed step by step, in order, from start to finish. The way we commonly imagine a computer works.

Parallel One task is split and processed by several processors at the same time.

Multi-agent Separate tasks or algorithms are processed by different systems called agents. Each is autonomous but they cooperate through negotiation and coordination. This is the basis of artificial intelligence.
