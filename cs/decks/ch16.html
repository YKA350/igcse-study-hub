Input

To change the meaning or format of data by following rules.

Output

Processed or stored data displayed or sent out.

Input, process, output

Input, process, output (2/3)

  1. A computer takes input from its surroundings, processes it by given rules and gives output.
  2. Embedded computers are fixed inside other objects, e.g. a washing machine: controls are inputs, the motor and heater are outputs.
  3. Desktop: keyboard and mouse in, screen out.
  4. Processing follows an algorithm, a precise step-by-step method.
Function machine

A diagram or metaphor of a machine that takes an input, applies a rule and delivers an answer.

Input, process, output (3/3)

  1. Anything beyond the simplest algorithm needs temporary storage (memory) to keep track of working.
  2. Flowchart symbols: a parallelogram shows input or output and a rectangle shows a process.
  3. Systems can be investigated by changing inputs and watching outputs, as Mendel did with peas.

Computational models

Computational models (1/2)

Sequential

Instructions are followed step by step, in order, from start to finish. The way we commonly imagine a computer works.

Parallel

One task is split and processed by several processors at the same time.

Multi-agent

Separate tasks or algorithms are processed by different systems called agents. Each is autonomous but they cooperate through negotiation and coordination. This is the basis of artificial intelligence.
