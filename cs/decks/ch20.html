Low-level languages (1/4)

Instruction set

The list of all possible commands a particular CPU knows how to do. Each has a binary code.

Machine code

The binary codes representing each instruction in the instruction set. The only language a CPU understands.

Low-level languages

Low-level languages (2/4)

  1. Programs are stored as binary numbers in memory.
  2. Machine code is too hard for humans and works only on one kind of CPU, because different CPUs have different instruction sets.
  3. A translator is a program that converts source code (the text a programmer writes) into machine code.
Assembly language

A low-level language written with mnemonics. One assembly instruction equals one machine code instruction.

Low-level languages (3/4)

Mnemonic

A short acronym for an instruction, e.g. LDR (load register), STR (store), CMP (compare), ADD.

Assembler

Translator that turns assembly language into machine code.

Low-level languages

Low-level languages (4/4)

  1. Low-level means working at the level of the CPU hardware.
  2. Hard because: only very few instructions are available, you manage all your data and memory yourself (no strings or integers), and debugging is very difficult (bugs just crash the machine and you reboot).
  3. Used now only for some hardware drivers and embedded systems needing very small, fast programs or direct I/O control.
  4. Elite (1980s) fitted in 22 KB of assembly.
  5. An emulator lets one computer behave like another. A reboot restarts a device.

High-level languages

High-level languages (1/3)

  1. Python, C#, Java and Visual Basic are high-level and close to human language.
  2. One statement does a lot, there are data types, and the code is much easier to write and debug.
  3. Source code must be translated into machine code to run.
  4. Graphical languages such as Scratch suit beginners, textual ones like Python are used for larger programs.

High-level languages

High-level languages (2/3)

Compiler

Translates the whole program at once into object code (often machine code, .exe) and saves it to run later.

Interpreter

Translates and runs the program one line at a time. There is no object code file, only source code.

Object code

The translated source code. Often machine code, but may be an intermediate code translated further before running.
