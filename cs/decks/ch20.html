Low-level languages

Low-level languages (1/5)

Instruction set

The list of all possible commands a particular CPU knows how to do. Each has a binary code.

Machine code

The binary codes representing each instruction in the instruction set. The only language a CPU understands.

Assembly language

A low-level language written with mnemonics. One assembly instruction equals one machine code instruction.

Low-level languages

Low-level languages (2/5)

Mnemonic

A short acronym for an instruction, e.g. LDR (load register), STR (store), CMP (compare), ADD.

Assembler

Translator that turns assembly language into machine code.

Programs are stored as binary numbers in memory.

Low-level languages (3/5)

Machine code is too hard for humans and works only on one kind of CPU, because different CPUs have different instruction sets.

A translator is a program that converts source code (the text a programmer writes) into machine code.

Low-level means working at the level of the CPU hardware.

Low-level languages (4/5)

Hard because

only very few instructions are available, you manage all your data and memory yourself (no strings or integers), and debugging is very difficult (bugs just crash the machine and you reboot).

Used now only for some hardware drivers and embedded systems needing very small, fast programs or direct I/O control.

Elite (1980s) fitted in 22 KB of assembly.

High-level languages (1/4)

Needs the interpreter installed on every computer: Object code runs on its own on similar computers

Finds errors as they happen, easier to debug: Produces no object code until the whole program is correct, many errors reported at first

Runs slower because translating while running: Runs faster

High-level languages

High-level languages (2/4)

Source code is given to users and can be copied: Only object code is shared, so code is harder to alter or copy

Object code

The translated source code. Often machine code, but may be an intermediate code translated further before running.

Compiler Translates the whole program at once into object code (often machine code,.exe) and saves it to run later.

High-level languages

High-level languages (3/4)

Interpreter Translates and runs the program one line at a time. There is no object code file, only source code.

Python, C#, Java and Visual Basic are high-level and close to human language.

One statement does a lot, there are data types, and the code is much easier to write and debug.

High-level languages

High-level languages (4/4)

Source code must be translated into machine code to run.

Graphical languages such as Scratch suit beginners, textual ones like Python are used for larger programs.
