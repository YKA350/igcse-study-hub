Representation of text

Representation of text (1/2)

ASCII

A code that represents text characters as patterns of 7 or 8 bits.

Exam tip Encryption can shift each character code, e.g. add a key to the code. This is covered in chapter 15.

Each character has a number, e.g. A is 65 and a is 97, stored as binary.

7 bits give 128 characters, 8 bits give 256.

Representation of text

Representation of text (2/2)

Capital letters are consecutive and so are lower-case letters.

Unicode uses more bits per character to cover many languages and symbols.

You can analyse a string by finding the ASCII code of each character, and build text back from codes.

Representation of images

Representation of images (1/2)

Pixel

The smallest single point of colour in a graphic image.

A bitmap image is a grid of pixels. Each pixel has a binary colour value.

Colour depth (bit depth) is the number of bits used per pixel. 1 bit gives 2 colours, 8 bits give 256, 24 bits give about 16.7 million.

Representation of images

Representation of images (2/2)

Resolution is the number of pixels, width by height.

More pixels or more bits per pixel mean better quality but a larger file.

Representation of sound

Representation of sound (1/2)

Analogue recording stores the continuously varying sound wave.

Digital recording samples the wave

its height is measured at regular intervals and stored as binary.

The sample rate is the number of samples per second, in hertz (Hz).

Representation of sound

Representation of sound (2/2)

The bit depth is the number of bits for each sample, so it sets how precise each measurement is.

Higher sample rate and bit depth give a better copy (fidelity) but bigger files.
