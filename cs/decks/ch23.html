The Internet

The Internet (1/3)

Internet

A worldwide network of interconnected networks and the biggest WAN of all. Links are cables, fibre-optic links and satellites, together called the backbone.

Internet service provider (ISP)

An organisation that provides customers with a connection to the Internet, often through telephone lines.

Domain name

Part of a URL that identifies a resource, easier to remember than an IP address, e.g. bbc.co.uk.

The Internet

The Internet (2/3)

Domain name service (DNS)

A network of servers that translates domain names into IP addresses. If one server cannot resolve a name it asks another.

User types a domain name into the browser.

The client asks a DNS server to resolve it.

The Internet

The Internet (3/3)

If the server does not know it, it asks another server which returns the address.

The IP address is returned to the client, which contacts the host using it.

The Internet

How data travels (1/2)

Router

Networking hardware that forwards packets from one network to another using a routing table.

Exam tip The Internet continues working if parts fail because routers can send packets by another route.

The sending computer splits data into packets.

Each header holds the sender address, destination address, packet number and total packets.

The Internet

How data travels (2/2)

Packets go to the ISP's router.

A router reads the destination IP and uses its routing table of rules to forward the packet.

This repeats across several routers.

The receiver reassembles the data. Packets may arrive out of order and are sorted using the header.

The World Wide Web

The Internet and the World Wide Web

The World Wide Web

The World Wide Web

World Wide Web (WWW)

A service running on the Internet giving access to web pages linked by hypertext. Invented in 1989 by Tim Berners-Lee. It is not the same as the Internet. Email is another Internet service.

Hypertext is text containing hyperlinks to other pages.

A web browser is the client and converts data from the web server into a readable page. A web server stores web pages and multimedia.

The World Wide Web

How a page is fetched (1/2)

HTML

A text document containing the text to display, how it is formatted (font, colour), the hyperlinks and where they link, and objects such as pictures or videos.

The user enters a web address, a URL (uniform resource locator), for a page or a single file.

The computer uses DNS to find the web server's IP address.

The World Wide Web

How a page is fetched (2/2)

The browser connects to the server using that IP address and requests the page.

The page is sent using HTTP or HTTPS.

It arrives as HTML (HyperText Markup Language) and the browser displays it as described.

IP addresses

The Internet and the World Wide Web

IP addresses

IP addresses (1/2)

An IP address identifies one computer like a postal address, so all must follow the same standard.

IPv4

four 8-bit numbers (octets), 32 bits, e.g. 216.27.61.137, about 4 billion addresses.

IP addresses

IP addresses (2/2)

IPv6

128 bits, eight groups of hexadecimal separated by colons, e.g. 2001:cdba:0000:0000:0000:0000:3257:9652. Far more addresses.

IPv6 was introduced because IPv4 addresses were running out.

Access hardware

Access hardware (1/2)

Switch Links computers on a LAN. It reads destination addresses and sends data only to the intended computer, cutting traffic.

Wireless access point (WAP) Lets wireless devices join a wired network using Wi-Fi. Transmits to all devices and cannot direct messages. Used for hotspots.

Access hardware

Access hardware (2/2)

Router Reads address information and sends data between networks, e.g. joins a home network to the Internet and can have cable and Wi-Fi.

Modem Short for modulator-demodulator. Converts signals so they can be sent along the ISP's copper or fibre cable. Usually combined with a router in one box.
