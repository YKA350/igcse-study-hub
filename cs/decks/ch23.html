The Internet (3/3)

  1. User types a domain name into the browser.
  2. The client asks a DNS server to resolve it.
  3. If the server does not know it, it asks another server which returns the address.
  4. The IP address is returned to the client, which contacts the host using it.

The Internet

How data travels (1/2)

  1. The sending computer splits data into packets.
  2. Each header holds the sender address, destination address, packet number and total packets.
  3. Packets go to the ISP's router.
  4. A router reads the destination IP and uses its routing table of rules to forward the packet.
  5. This repeats across several routers.
  6. The receiver reassembles the data. Packets may arrive out of order and are sorted using the header.
Router

Networking hardware that forwards packets from one network to another using a routing table.

The World Wide Web

The World Wide Web

World Wide Web (WWW)

A service running on the Internet giving access to web pages linked by hypertext. Invented in 1989 by Tim Berners-Lee. It is not the same as the Internet. Email is another Internet service.

  1. Hypertext is text containing hyperlinks to other pages.
  2. A web browser is the client and converts data from the web server into a readable page. A web server stores web pages and multimedia.
Spec 5.3.2, 5.3.4 Understand what is meant by the world wide web
The World Wide Web

How a page is fetched (1/2)

  1. The user enters a web address, a URL (uniform resource locator), for a page or a single file.
  2. The computer uses DNS to find the web server's IP address.
  3. The browser connects to the server using that IP address and requests the page.
  4. The page is sent using HTTP or HTTPS.
  5. It arrives as HTML (HyperText Markup Language) and the browser displays it as described.
HTML

A text document containing the text to display, how it is formatted (font, colour), the hyperlinks and where they link, and objects such as pictures or videos.

IP addresses

The Internet and the World Wide Web

IP addresses

IP addresses

  1. An IP address identifies one computer like a postal address, so all must follow the same standard.
  2. IPv4: four 8-bit numbers (octets), 32 bits, e.g. 216.27.61.137, about 4 billion addresses.
  3. IPv6: 128 bits, eight groups of hexadecimal separated by colons, e.g. 2001:cdba:0000:0000:0000:0000:3257:9652. Far more addresses.
  4. IPv6 was introduced because IPv4 addresses were running out.

Access hardware

Access hardware (1/2)

Switch

Links computers on a LAN. It reads destination addresses and sends data only to the intended computer, cutting traffic.

Wireless access point (WAP)

Lets wireless devices join a wired network using Wi-Fi. Transmits to all devices and cannot direct messages. Used for hotspots.

Access hardware

Access hardware (2/2)

Router

Reads address information and sends data between networks, e.g. joins a home network to the Internet and can have cable and Wi-Fi.

Modem

Short for modulator-demodulator. Converts signals so they can be sent along the ISP's copper or fibre cable. Usually combined with a router in one box.
