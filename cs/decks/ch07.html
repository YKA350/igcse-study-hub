What a string is

What a string is (1/2)

String

A sequence of characters: letters, numbers, symbols, punctuation or spaces. All are treated as text.

Strings are enclosed in quotation marks so the computer can tell them from variable names and instructions.

Single or double quotes are fine if used consistently. In "It's her book" the apostrophe is part of the string.

What a string is

What a string is (2/2)

Examples

'johnsmith@mail.com', '10/04/15', '123'.

Strings are used to communicate with users, e.g. asking for input and showing output.

Concatenation and comparing

Concatenation and comparing (1/2)

Concatenation

Joining two or more items of information together to make a new string.

Edexcel pseudocode uses & to join. Python and C# use +.

Literal text is in quotes but the variable name is not.

Concatenation and comparing

Concatenation and comparing (2/2)

In Python you cannot join a string to a number. Convert the number with str(length) first. Java and C# can join most data types.

Compare strings with == in Python and C#. Java needs the equals method, e.g. food.equals("pie").
