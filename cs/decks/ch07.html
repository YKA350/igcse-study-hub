What a string is

String

A sequence of characters: letters, numbers, symbols, punctuation or spaces. All are treated as text.

  1. Strings are enclosed in quotation marks so the computer can tell them from variable names and instructions.
  2. Single or double quotes are fine if used consistently. In "It's her book" the apostrophe is part of the string.
  3. Examples: 'johnsmith@mail.com', '10/04/15', '123'.
  4. Strings are used to communicate with users, e.g. asking for input and showing output.

String traversal

Using a loop to cycle through each character in a string.

SET animalName TO 'monkey'
FOR index = 0 TO LENGTH(animalName)
  SEND animalName[index] TO DISPLAY
END FOR
  1. The loop prints each letter on its own line.
  2. It must stop at LENGTH − 1, here index 5, because indexes start at 0.
  3. In Python range does not include the end number, so use range(0, len(animalName)) without subtracting 1.
  4. Practice: check whether a car make entered is in a given string of makes, ignoring case.

Concatenation and comparing (1/2)

Concatenation

Joining two or more items of information together to make a new string.

RECEIVE userName FROM (STRING) KEYBOARD
SEND 'Hello' & userName TO DISPLAY
  1. Edexcel pseudocode uses & to join. Python and C# use +.
  2. Literal text is in quotes but the variable name is not.
  3. In Python you cannot join a string to a number. Convert the number with str(length) first. Java and C# can join most data types.
  4. Compare strings with == in Python and C#. Java needs the equals method, e.g. food.equals("pie").
