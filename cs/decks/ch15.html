This chapter in a nutshell

Encryption keeps data secure so only the intended recipient can read it.

Plain text becomes cipher text using a key; decryption reverses it.

Symmetric uses one key; asymmetric uses two.

Ciphers: pigpen, Caesar (shift), Vigenère (keyword), rail fence (zigzag).

Encryption

Why and how

Why and how

  1. Encryption makes sensitive data secure.
  2. Keys encrypt data into cipher text and decrypt it back into plain text.
  3. Symmetric encryption uses the same key for both. The key must be shared safely.
  4. Asymmetric encryption uses two different keys, a public key to encrypt and a private key to decrypt.

Pigpen cipher

Pigpen cipher

  1. Each letter is replaced by a symbol from grids of lines and dots.
  2. It is simple to break because the same letter always gives the same symbol.

Caesar cipher

Caesar cipher (3/3)

  1. To decrypt, shift back by the same key.
  2. There are only 25 possible shifts so it is easy to crack.
  3. An algorithm loops through each character, adds the key to its code and wraps round after Z.

Caesar cipher: shift by 3

Encrypt

Replace each letter with the one a fixed number of places further on.

Decrypt

Shift back by the same amount.

Weakness

Only 25 possible keys, so it is easy to crack by trying them all (brute force).

Vigenère cipher

Encryption

Vigenère cipher

Vigenère cipher

  1. Uses a keyword repeated along the message and a grid of 26 shifted alphabets.
  2. The keyword letter decides the shift for each plain-text letter.
  3. The same plain letter can give different cipher letters, so it is harder to break than Caesar.
  4. Decrypt using the same keyword and the grid.

Rail fence cipher

Rail fence cipher (1/2)

  1. Write the message in a zigzag across a number of rails given by the key.
  2. Read each rail in turn to get the cipher text.
  3. This is a transposition cipher, so letters are moved, not replaced.
