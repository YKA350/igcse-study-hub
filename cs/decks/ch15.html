Why and how

Encryption

Why and how

Why and how (1/2)

Encryption makes sensitive data secure.

Keys encrypt data into cipher text and decrypt it back into plain text.

Symmetric encryption uses the same key for both. The key must be shared safely.

Why and how

Why and how (2/2)

Asymmetric encryption uses two different keys, a public key to encrypt and a private key to decrypt.

Pigpen cipher

Encryption

Pigpen cipher

Pigpen cipher

Each letter is replaced by a symbol from grids of lines and dots.

It is simple to break because the same letter always gives the same symbol.

Caesar cipher

Encryption

Caesar cipher

Caesar cipher (1/2)

Caesar cipher

Each letter is shifted a set number of places along the alphabet. The number of places is the key.

To decrypt, shift back by the same key.

There are only 25 possible shifts so it is easy to crack.

Caesar cipher

Caesar cipher (2/2)

An algorithm loops through each character, adds the key to its code and wraps round after Z.

Vigenère cipher

Encryption

Vigenère cipher

Vigenère cipher (1/2)

Uses a keyword repeated along the message and a grid of 26 shifted alphabets.

The keyword letter decides the shift for each plain-text letter.

The same plain letter can give different cipher letters, so it is harder to break than Caesar.

Vigenère cipher

Vigenère cipher (2/2)

Decrypt using the same keyword and the grid.

Rail fence cipher

Encryption

Rail fence cipher

Rail fence cipher

Write the message in a zigzag across a number of rails given by the key.

Read each rail in turn to get the cipher text.

This is a transposition cipher, so letters are moved, not replaced.
