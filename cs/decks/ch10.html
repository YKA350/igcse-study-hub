A predefined subprogram, e.g. one that averages numbers, can be used without knowing how it works. This supports abstraction.

In a flowchart a subprogram has its own symbol, a rectangle with extra vertical lines.

Local and global variables

Local and global variables

Scope

The region of code within which a variable is visible. Using a local variable outside its subprogram gives an error.

Local variable Created in a subprogram and only accessible from within it, e.g. simDie. Its scope is the subprogram.

Global variable Can be accessed from anywhere in the program, including inside subprograms, e.g. dieThrow in the main program.

Arguments and parameters (1/2)

Argument

A value passed from the main program to a subprogram.

Parameter

The name of the variable in the subprogram that stores the data passed in.

rectangleLength and rectangleWidth are arguments. length and width are parameters.
