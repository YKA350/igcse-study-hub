This chapter in a nutshell

A subprogram is a self-contained, reusable module that does one task.

A function returns a value; a procedure does not.

Arguments are passed in and received as parameters.

Local variables exist only inside a subprogram; global variables work everywhere.

Menus can send users to procedures.

Subprograms support abstraction.

Subprogram

A self-contained module of code that performs a specific task and can be called when needed.

  1. Programs become shorter because commands are not repeated.
  2. Code is more structured and easier to read.
  3. A predefined subprogram, e.g. one that averages numbers, can be used without knowing how it works. This supports abstraction.
  4. In a flowchart a subprogram has its own symbol, a rectangle with extra vertical lines.

Functions

FUNCTION dice ()
  SET simDie TO RANDOM(6)
  RETURN simDie
END FUNCTION
SET dieThrow TO dice()
  1. A function returns a value to the main program that called it.
  2. RANDOM(6) is a predefined function giving 1 to 6.
  3. The returned value is stored in dieThrow.
  4. C# is an OOP language so it has methods instead of functions. In an OOP language data and program elements are combined into one structure called an object.

Functions and procedures

Procedures (1/2)

PROCEDURE averageScore(score1, score2, score3)
BEGIN PROCEDURE
  SET total TO score1 + score2 + score3
  SET average TO total / 3
  SEND average TO DISPLAY
END PROCEDURE
  1. A procedure does not return a value to the main program.
  2. Python is the same without the return command.
  3. Java uses the keyword void to show that a subprogram returns nothing. In C# the equivalent is a method that returns no value.

Local and global variables

Local and global variables

Local variable

Created in a subprogram and only accessible from within it, e.g. simDie. Its scope is the subprogram.

Global variable

Can be accessed from anywhere in the program, including inside subprograms, e.g. dieThrow in the main program.

Scope

The region of code within which a variable is visible. Using a local variable outside its subprogram gives an error.

Arguments and parameters (1/2)

Argument

A value passed from the main program to a subprogram.

Parameter

The name of the variable in the subprogram that stores the data passed in.

def rectangle(length, width):
  area = length * width
  return area
rectangleArea = rectangle(rectangleLength, rectangleWidth)

Arguments and parameters (2/2)
