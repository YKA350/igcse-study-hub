Main memory

Hardware

Main memory

Main memory (1/4)

Memory address

A number that uniquely identifies a storage location. Addresses start at 0, like numbered letter boxes each holding 1 byte.

RAM Random-access memory. A temporary store for data and programs in use. Volatile, so contents are lost when power is off. Typically measured in gigabytes.

Main memory

Main memory (2/4)

ROM Read-only memory. Cannot be altered and keeps contents without power. Holds firmware such as the BIOS or UEFI that starts the hardware and operating system.

Cache Small, fast, expensive memory between devices working at different speeds, usually the CPU and RAM. Frequently used data is loaded in chunks. A cache miss happens when the data needed is not there and the CPU has to wait.

Main memory

Main memory (3/4)

Writing is when the CPU sends data to memory to be stored at an address. Reading is when it retrieves data from an address.

Volatile memory loses data when power is off. Non-volatile memory does not.

Cache was introduced because CPUs became much faster than RAM, causing a bottleneck.

Main memory

Main memory (4/4)

I/O devices use buffers (disk, print, frame buffer) so the CPU can carry on while the slow device reads at its own rate. Print spooling is an example.

Main memory

Virtual memory (1/2)

When RAM is full the operating system's memory manager swaps data out to a swap area on the hard disk and swaps in what is needed. The least recently used data is swapped out.

Drawbacks

the hard drive is much slower than RAM and heavy use hurts performance.

Disk thrashing is constant swapping that slows programs.

Virtual memory (2/2)

More RAM means less virtual memory is needed.

Inside the CPU

Hardware

Inside the CPU

Inside the CPU (1/4)

Accumulator

Holds results of ALU calculations. All input and output pass through it

Program counter

Holds the address of the next instruction to fetch

Current instruction register

Holds the instruction being executed

Inside the CPU

Inside the CPU (2/4)

Arithmetic/logic unit (ALU)

The part of the CPU that does calculations and logic operations.

Control unit

The part of the CPU that organises the actions of the other parts.

Register

A very fast storage location inside the CPU holding an instruction, an address or a single item of data.

Inside the CPU

Inside the CPU (3/4)

Clock

An electronic device that ticks at regular intervals to synchronise the CPU. 2.2 GHz means 2200 million ticks per second.

Address bus Carries memory addresses between the CPU and memory.

Data bus Carries the values read from or written to memory.

Inside the CPU

Inside the CPU (4/4)

Control bus Carries signals such as whether to read or write, and when.

Bus width is the number of wires. An 8-bit address bus can send 0 to 255, so only 256 addresses. A 32-bit computer can address up to 4 GB of RAM.

Inside the CPU

Fetch-decode-execute cycle (1/2)

Fetch

the control unit puts the next instruction's address on the address bus and signals read on the control bus. The memory copies the instruction onto the data bus and the CPU stores it in a register.

Decode

the control unit analyses the instruction and signals the other CPU parts what to do.

Execute

the CPU completes the instruction, e.g. adds numbers or stores data.

Inside the CPU

Fetch-decode-execute cycle (2/2)

Billions of simple instructions per second create complex behaviour. I/O devices have addresses too.

CPU performance

Hardware

CPU performance

CPU performance (1/2)

Clock speed Faster clock means more instructions per second. About 3 GHz is common. Limits: transistor speed and heat. A fan and heat sink cool the chip, and 9 GHz needs liquid nitrogen.

Number of cores A multicore processor (dual, quad, octa) has several cores but one CPU, introduced in 2006. Cores can share one program (parallel processing) or run different programs (multitasking).

CPU performance

CPU performance (2/2)

Sequential tasks that need earlier results cannot speed up.

Size of cache A larger cache means more chance the data is already there, so fewer RAM accesses. Static RAM (SRAM) is used. L1 is fastest and smallest, checked first, then L2, then L3.

In multicore chips each core has its own L1 and L2 and the last-level cache is shared.

Secondary storage

Hardware

Secondary storage

Secondary storage (1/3)

Secondary storage

Permanent, non-volatile storage to which the contents of RAM and ROM are copied. Slower and cheaper than RAM with much higher capacity, now terabytes.

Magnetic (hard disks) Platters with a magnetic coating spin, with heads on an arm floating very close. North and south poles represent 1s and 0s. Data is on circular tracks split into sectors.

Secondary storage

Secondary storage (2/3)

Reading involves seek time (arm moves to the track) and latency (waiting for the sector).

Optical (CD, DVD, Blu-ray) Data is in a spiral track. Pits (non-reflective) and lands (flat reflective) are read by a laser and a light sensor. Writing heats the layer, which is slow. Rotation slows towards the outside edge.

Secondary storage

Secondary storage (3/3)

Solid state (flash, USB, SD) NAND flash transistors trap electrons in pools. A full pool is 0 and empty is 1.

Faster, smaller, no moving parts, but wears out after about a million rewrites because high voltage for writing and erasing breaks transistors down.

Future ideas

memristors, racetrack memory, quantum computers using qubits.

Secondary storage

Cloud storage (1/2)

Cloud storage

Secondary storage owned by a third party and accessed via a network, usually the Internet.

Virtualisation

Hiding the physical nature of a computing resource so it looks different, e.g. a single virtual drive spread over many servers.

Secondary storage

Cloud storage (2/2)

File servers share storage over a network. NAS is network-attached storage. A SAN connects several servers to shared storage, so if one fails another takes over, useful for banking.

Advantages of cloud

access anywhere on many devices, backed up by the provider, no data transfer to a new computer.

Disadvantages

security and privacy worries, needs an Internet connection, data not physically in your hand.

Embedded systems

Embedded systems (1/2)

Embedded system

A computer designed to do a specific job, usually part of a bigger system such as a washing machine, car, traffic lights or toy.

Internet of things (IoT)

Interconnection of digital devices embedded in everyday objects, controlled over the Internet, e.g. a printer ordering toner or heating controlled from a phone.

Usually cheap, low-power, limited memory, often use sensors.

Embedded systems

Embedded systems (2/2)

Run one program rarely updated, stored in firmware (ROM or flash).

Different from general-purpose PCs and laptops.

Engine management inputs

sensors for speed and temperature. Outputs: fuel injection and spark timing.
