This chapter in a nutshell

Computers need unambiguous instructions, so we use the three constructs: sequence, selection and iteration.

Selection is a choice (IF … THEN … ELSE).

Iteration repeats steps (a loop).

Flowcharts and pseudocode show all three.

Why wording matters (1/2)

  1. A human understands "wait for the water to boil" and keeps checking.
  2. A computer would just wait forever.

Why wording matters (2/2)

Sequence

Step-by-step instructions in the correct order.

Selection

A choice is made between alternatives, e.g. IF the water is at 100 °C then turn off the kettle.

Iteration

A process is repeated until a condition is met. It is often called a loop.

Selection and iteration in flowcharts

Representing them

  1. Selection is a question (diamond) with two alternatives, YES and NO.
  2. Iteration is a question where the NO arrow goes back and repeats the question until the answer is YES.
  3. Example: check temperature of water = 100 °C. If NO, check again. If YES, turn off kettle and pour water.

Selection in pseudocode

Calculating grades (1/3)

RECEIVE testScore FROM KEYBOARD
IF testScore >= 80 THEN
  SEND 'A' TO DISPLAY
ELSE
  IF testScore >= 70 THEN
    SEND 'B' TO DISPLAY
  ELSE
    IF testScore >= 60 THEN
      SEND 'C' TO DISPLAY
    ELSE
      IF testScore > 0 THEN
        SEND 'D' TO DISPLAY
      ELSE
        SEND 'FAIL' TO DISPLAY
      END IF
    END IF
  END IF
END IF
