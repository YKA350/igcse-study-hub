This chapter in a nutshell

An algorithm is a precise sequence of steps that solves a problem.

A good algorithm is accurate, consistent and efficient.

Algorithms can be shown as written descriptions, flowcharts or pseudocode.

An algorithm is the design; a program is the design implemented in a language.

Variables hold values that can change; constants hold values that never change.

What an algorithm is

Definition and example (1/2)

Algorithm

A precise method for solving a problem. It is a sequence of steps with a start and an end.

  1. It is unambiguous: the instructions cannot be misunderstood, e.g. "turn left" is clear but "turn" is ambiguous.
  2. It can be used again and always gives the same result.
  3. It provides a solution to a problem.
  4. Most problems have more than one solution, so different algorithms can solve the same problem.

What an algorithm is

Successful algorithms

Accuracy

It must lead to the expected outcome, e.g. create a route from one city to another.

Consistency

It must produce the same result every time it is run.

Efficiency

It must solve the problem in the shortest time using as few computer resources as possible.

Exam tipSome sorting and searching algorithms are far more efficient than others. A new method is only an improvement if it is faster than the old one, such as an atlas.

What an algorithm is

Algorithms and programs

  1. An algorithm is a detailed design for a solution.
  2. A program is that design implemented in a programming language.
  3. Algorithms are first designed, then coded in a high-level language, which is similar to natural human language.

Displaying algorithms

Written descriptions

  1. The simplest way to express an algorithm.
  2. Example, making instant coffee: fill kettle, turn on kettle, place coffee in cup, wait for water to boil, pour water into cup, add milk and sugar, stir.
  3. Everyday tasks such as a recipe or flat-pack instructions are algorithms.
Careful"Wait for water to heat" is ambiguous because how hot is not stated. A computer algorithm must say "wait until the water reaches 100 °C".

Displaying algorithms

Pseudocode

Pseudocode

A structured, code-like language used to describe an algorithm without the rules of any particular programming language.

  1. It lets a developer concentrate on logic and efficiency.
  2. It is easy to translate into any high-level language.
  3. Different exam boards have their own versions. This course uses the Pearson Edexcel pseudocode.

Displaying algorithms

Worked example: adding two numbers

SEND 'Please enter the first number' TO DISPLAY
RECEIVE firstNumber FROM KEYBOARD
SEND 'Please enter the second number' TO DISPLAY
RECEIVE secondNumber FROM KEYBOARD
SET total TO firstNumber + secondNumber
SEND total TO DISPLAY
  1. The two numbers typed in are stored in variables firstNumber and secondNumber.
  2. The result is stored in the variable total.
  3. Text to display goes in quotation marks, single or double.
  4. No quotation marks when you want a variable displayed, otherwise the word total is shown instead of its value.

Operators, variables and constants

Identifiers and naming

  1. Every variable and constant needs a unique identifier.
  2. Use descriptive names, e.g. firstName rather than X.
  3. Long names are easier to misspell, so keep them sensible.
  4. Camel case: firstName. Capitals for each word: FirstName. Snake case: first_name.
  5. Pick one convention and use it consistently.
Exam tipBe careful not to confuse a descriptive name with a long name. firstName tells the reader what data it holds.
