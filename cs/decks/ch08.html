Arrays

Arrays (1/2)

Data structure

An organised collection of related elements, such as strings, arrays and records.

Array

A structure that holds many items of the same data type with one shared identifier. Each item has a unique index giving its position.

Square brackets mark the start and end of the array.

Arrays

Arrays (2/2)

A static array has a fixed size stated when it is declared, e.g. array friends[5].

Like strings, arrays have a length. Python len(myArray), Java myArray.length, C# myArray.Length.

Use a loop to traverse an array and print every item.

Arrays

Lists

Python uses lists instead of arrays. They are dynamic, so they can grow as items are added, e.g. cars.append('Audi').

Python lists can mix data types.

Java arrays are static. You cannot add or remove items, so use an ArrayList (dynamic) to add and remove. A vector can hold mixed types.

C# supports both lists and arrays.

Two-dimensional arrays

Two-dimensional arrays (1/2)

Multidimensional array

An array of arrays. Each item at an index is itself another array.

Exam tip All values in an array must be the same type, so in Java strings must be converted to integers to compare scores. Python lists avoid this.

array cars[3, 2] means 3 rows with 2 items in each.

Two-dimensional arrays

Two-dimensional arrays (2/2)

Each item has two indexes, row first then column, e.g. examResults[1, 2] is the second row, third item.

In Python it is written results[0][1], not results[0, 1]. In Java the first index is the row and the second is the column.

A 3-row, 4-column table is [[80, 59, 34, 89], [31, 11, 47, 64], [29, 56, 13, 91]].

Record

A data structure that stores a set of related values of different data types.

Field

An individual element in a record, referenced by its field name.

Languages handle records differently.
