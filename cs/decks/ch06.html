Why readability matters

Why readability matters

  1. Developers work in teams, each writing a different part. They must understand each other's code, especially when fixing errors.
  2. You forget quickly, so readable code helps you too.
  3. Complex programs have many variables, subprograms, nested loops and selections, so they are hard to read without good style.
  4. Large programs such as Windows have around 50 million lines of code.
Exam tipA poor example uses names like Num1 and Num2, no blank lines and no comments. Better: userChoice and computerChoice with comments for each block.

Four techniques

TechniqueDescription
CommentsExplain what each part of the program does
Descriptive namesIdentifiers for variables, constants and subprograms show their purpose
IndentationShows where each block of code starts and finishes. In Python wrong indentation stops the program or gives wrong results
White spaceBlank lines between blocks make them stand out

Four techniques

Writing comments

  1. Python: start each comment line with #.
  2. Java and C#: // for a single line, /* … */ for several lines.
  3. A block of code is a grouping of two or more statements.
