Why readability matters

Why readability matters (1/2)

Exam tip A poor example uses names like Num1 and Num2, no blank lines and no comments. Better: userChoice and computerChoice with comments for each block.

Developers work in teams, each writing a different part. They must understand each other's code, especially when fixing errors.

You forget quickly, so readable code helps you too.

Why readability matters

Why readability matters (2/2)

Complex programs have many variables, subprograms, nested loops and selections, so they are hard to read without good style.

Large programs such as Windows have around 50 million lines of code.

Four techniques (1/2)

Comments

Explain what each part of the program does

Descriptive names

Identifiers for variables, constants and subprograms show their purpose

Indentation

Shows where each block of code starts and finishes. In Python wrong indentation stops the program or gives wrong results
