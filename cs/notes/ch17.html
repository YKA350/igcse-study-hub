1Stored programs: the von Neumann model
Stored programs: the von Neumann model
Von Neumann architecture

A computer design where the program instructions are stored in memory together with the data. Also called a stored-program computer.

  1. Every computer has four functions: input, output, storage and processing.
  2. A calculator does one job, a smartphone is general purpose.
  3. Early machines like ENIAC (1940s) had to be rewired for each job; six women did this reprogramming.
  4. Ada Lovelace is recognised as the first programmer, working on Babbage's mechanical machine.
  5. Turing and von Neumann proposed holding instructions with the data.
  6. Instructions and data are both binary numbers.
Central processing unit (CPU)

The hardware device that carries out the processing in a computer.

Bus

A group of connecting wires between devices in a computer.

  1. The CPU fetches an instruction, carries it out, then fetches the next until the power is turned off.
  2. Input devices such as keyboards, mice and light sensors give data to the computer.
  3. Output devices such as monitors, printers and speakers show results.
2Main memory
Main memory
Memory address

A number that uniquely identifies a storage location. Addresses start at 0, like numbered letter boxes each holding 1 byte.

  1. Writing is when the CPU sends data to memory to be stored at an address. Reading is when it retrieves data from an address.

RAM

Random-access memory. A temporary store for data and programs in use. Volatile, so contents are lost when power is off. Typically measured in gigabytes.

ROM

Read-only memory. Cannot be altered and keeps contents without power. Holds firmware such as the BIOS or UEFI that starts the hardware and operating system.

Cache

Small, fast, expensive memory between devices working at different speeds, usually the CPU and RAM. Frequently used data is loaded in chunks. A cache miss happens when the data needed is not there and the CPU has to wait.

  1. Volatile memory loses data when power is off. Non-volatile memory does not.
  2. Cache was introduced because CPUs became much faster than RAM, causing a bottleneck.
  3. I/O devices use buffers (disk, print, frame buffer) so the CPU can carry on while the slow device reads at its own rate. Print spooling is an example.
Virtual memory
  1. When RAM is full the operating system's memory manager swaps data out to a swap area on the hard disk and swaps in what is needed. The least recently used data is swapped out.
  2. Drawbacks: the hard drive is much slower than RAM and heavy use hurts performance.
  3. Disk thrashing is constant swapping that slows programs.
  4. More RAM means less virtual memory is needed.
3Inside the CPU
Inside the CPU
Arithmetic/logic unit (ALU)

The part of the CPU that does calculations and logic operations.

Control unit

The part of the CPU that organises the actions of the other parts.

Register

A very fast storage location inside the CPU holding an instruction, an address or a single item of data.

Clock

An electronic device that ticks at regular intervals to synchronise the CPU. 2.2 GHz means 2200 million ticks per second.

RegisterRole
AccumulatorHolds results of ALU calculations. All input and output pass through it
Program counterHolds the address of the next instruction to fetch
Current instruction registerHolds the instruction being executed

Address bus

Carries memory addresses between the CPU and memory.

Data bus

Carries the values read from or written to memory.

Control bus

Carries signals such as whether to read or write, and when.

  1. Bus width is the number of wires. An 8-bit address bus can send 0 to 255, so only 256 addresses. A 32-bit computer can address up to 4 GB of RAM.
Fetch-decode-execute cycle
  1. Fetch: the control unit puts the next instruction's address on the address bus and signals read on the control bus. The memory copies the instruction onto the data bus and the CPU stores it in a register.
  2. Decode: the control unit analyses the instruction and signals the other CPU parts what to do.
  3. Execute: the CPU completes the instruction, e.g. adds numbers or stores data.
  4. Billions of simple instructions per second create complex behaviour. I/O devices have addresses too.
4CPU performance
CPU performance

Clock speed

Faster clock means more instructions per second. About 3 GHz is common. Limits: transistor speed and heat. A fan and heat sink cool the chip, and 9 GHz needs liquid nitrogen.

Number of cores

A multicore processor (dual, quad, octa) has several cores but one CPU, introduced in 2006. Cores can share one program (parallel processing) or run different programs (multitasking). Sequential tasks that need earlier results cannot speed up.

Size of cache

A larger cache means more chance the data is already there, so fewer RAM accesses. Static RAM (SRAM) is used. L1 is fastest and smallest, checked first, then L2, then L3. In multicore chips each core has its own L1 and L2 and the last-level cache is shared.

5Secondary storage
Secondary storage
Secondary storage

Permanent, non-volatile storage to which the contents of RAM and ROM are copied. Slower and cheaper than RAM with much higher capacity, now terabytes.

Magnetic (hard disks)

Platters with a magnetic coating spin, with heads on an arm floating very close. North and south poles represent 1s and 0s. Data is on circular tracks split into sectors. Reading involves seek time (arm moves to the track) and latency (waiting for the sector).

Optical (CD, DVD, Blu-ray)

Data is in a spiral track. Pits (non-reflective) and lands (flat reflective) are read by a laser and a light sensor. Writing heats the layer, which is slow. Rotation slows towards the outside edge.

Solid state (flash, USB, SD)

NAND flash transistors trap electrons in pools. A full pool is 0 and empty is 1. Faster, smaller, no moving parts, but wears out after about a million rewrites because high voltage for writing and erasing breaks transistors down.

  1. Future ideas: memristors, racetrack memory, quantum computers using qubits.
Cloud storage
Cloud storage

Secondary storage owned by a third party and accessed via a network, usually the Internet.

Virtualisation

Hiding the physical nature of a computing resource so it looks different, e.g. a single virtual drive spread over many servers.

  1. File servers share storage over a network. NAS is network-attached storage. A SAN connects several servers to shared storage, so if one fails another takes over, useful for banking.
  2. Advantages of cloud: access anywhere on many devices, backed up by the provider, no data transfer to a new computer.
  3. Disadvantages: security and privacy worries, needs an Internet connection, data not physically in your hand.
6Embedded systems
Embedded systems
Embedded system

A computer designed to do a specific job, usually part of a bigger system such as a washing machine, car, traffic lights or toy.

  1. Usually cheap, low-power, limited memory, often use sensors.
  2. Run one program rarely updated, stored in firmware (ROM or flash).
  3. Different from general-purpose PCs and laptops.
  4. Engine management inputs: sensors for speed and temperature. Outputs: fuel injection and spark timing.
Internet of things (IoT)

Interconnection of digital devices embedded in everyday objects, controlled over the Internet, e.g. a printer ordering toner or heating controlled from a phone.
