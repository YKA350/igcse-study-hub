Data structures

Computer Science · Programming · Last-minute notes · Book pages 62–69

Chapter in a nutshell

  • A data structure is an organised collection of related elements.
  • An array holds many items of the same type under one name and a unique index, starting at 0.
  • A 2D array is an array of arrays, read as array[row, column].
  • A record stores related fields of different types.
  • Static arrays have a fixed size; lists are dynamic.
1Arrays
Arrays
Data structure

An organised collection of related elements, such as strings, arrays and records.

Array

A structure that holds many items of the same data type with one shared identifier. Each item has a unique index giving its position.

SET firstNames TO ['Ashura', 'Bryn', 'Eloise', 'Mei']
  1. Square brackets mark the start and end of the array.
  2. A static array has a fixed size stated when it is declared, e.g. array friends[5].
  3. Like strings, arrays have a length. Python len(myArray), Java myArray.length, C# myArray.Length.
  4. Use a loop to traverse an array and print every item.
Lists
  1. Python uses lists instead of arrays. They are dynamic, so they can grow as items are added, e.g. cars.append('Audi').
  2. Python lists can mix data types.
  3. Java arrays are static. You cannot add or remove items, so use an ArrayList (dynamic) to add and remove. A vector can hold mixed types.
  4. C# supports both lists and arrays.
Linear search in an array
SET found TO False
SET index TO 0
WHILE found = False AND index <= (LENGTH(firstNames) - 1) DO
  IF searchName = firstNames[index] THEN
    SET found TO True
  END IF
  SET index TO index + 1
END WHILE
  1. found is a status flag, False until the name is matched.
  2. The loop stops when found or at the end of the array.

Two-dimensional arrays
Multidimensional array

An array of arrays. Each item at an index is itself another array.

  1. array cars[3, 2] means 3 rows with 2 items in each.
  2. Each item has two indexes, row first then column, e.g. examResults[1, 2] is the second row, third item.
  3. In Python it is written results[0][1], not results[0, 1]. In Java the first index is the row and the second is the column.
  4. A 3-row, 4-column table is [[80, 59, 34, 89], [31, 11, 47, 64], [29, 56, 13, 91]].

3Records
Records
Record

A data structure that stores a set of related values of different data types.

Field

An individual element in a record, referenced by its field name.

learnerNumfirstNamelastNameageform
1IslaSmith1510H
2ShinjiFujita1410B
  1. Each row is one record about one learner.
  2. Each column is a field.
  3. Every value in a column has the same type: learnerNum and age are integers, the names and form are strings.
  4. Languages handle records differently.
