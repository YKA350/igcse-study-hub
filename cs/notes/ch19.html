Software

Computer Science · Computers · Last-minute notes · Book pages 187–193

Chapter in a nutshell

  • Software is programs; hardware is the physical parts.
  • Application software does user tasks; system software is the OS plus utilities.
  • The OS manages files, hardware, processes, memory, users and the user interface.
  • Utility software: file management, security and basic tools.
  • Simulation models the real world using abstraction.
1Types of software
Types of software
Software

The set of programs run by a computer system.

Application software

Does a task that would otherwise be done by hand, e.g. a word processor or spreadsheet.

System software

Helps use the computer and applications. Divided into operating systems and utility software.

2Operating systems
Operating systems
Operating system (OS)

Software designed for particular hardware that manages other programs' access to the hardware. Examples: Windows, Linux, Android, iOS.

  1. A general-purpose computer needs software that runs on different hardware. The OS manages input and output devices.
  2. The programmer uses simple commands like OpenFile and the OS handles how. This is abstraction.
  3. Apps are written for a particular OS but work on any hardware that runs it, e.g. Android apps work on any Android device.
  4. The OS sits between the hardware and the programs.
Application programming interface (API)

Code that lets two programs communicate, e.g. OpenFile or DisplayJPEG offered by the OS to developers. Using the API means programs do not touch hardware directly, which reduces crashes and helps security.

Driver

Software that communicates with an I/O device on the bus and moves data between it and the OS in an agreed format (the API).

Jobs of the operating system

Managing files

Controls the directory structure, input and output and file access.

Scheduling

A von Neumann computer does one thing at a time, so the OS gives each program the CPU for a short time before switching, creating the illusion that they run together. Round-robin is one method.

Paging / virtual memory

When RAM is full the OS moves programs from RAM to disk and back when needed. Many open applications can slow the computer.

Managing processes

Each running task is a process, including background ones like the network manager, scheduler, drivers and antivirus. Task Manager (Windows), ps aux (Linux) and Activity Monitor (OSX) list them with CPU use and memory use.

Managing users

Multi-user systems need authentication (username and password or fingerprint) to prove who you are. Rights depend on who you are. A super-user (administrator or root) controls all resources and rights. A phone is single-user, school servers are multi-user.

User interface

A GUI uses windows, icons, menus and pointers (WIMP). A command-line interface (CLI) is text only. A web server may need only a CLI, video editing needs a GUI, and embedded systems may have no OS or interface.

Concurrent

Processes that appear to run at the same time. An OS that allows this is a multitasking OS.

3Utility software
Utility software
Utility software

Software that does a useful job for the user that is not essential to the operating system and not the reason for using the computer. Three areas: basic tools, file management and security.

Basic tools

Text editor (Notepad, nano), calculator, command prompt, hex editor and accessibility software such as large print. Usually included with the OS.

File management

Back-up (a copy of files elsewhere), recovering deleted files, repairing damaged files, converting file formats (e.g. jpg, gif, png), compression, and defragmentation.

Defragmenter

A utility that moves a file's clusters closer together on a magnetic hard disk to speed access. Not needed on solid state drives because access time is the same everywhere.

  1. Compressed files free space but are slower to open because they must be uncompressed.
  2. Do not confuse compression with encryption.

Security tools

Antivirus and anti-spyware find code that copies itself or records private data. A virus copies itself and spreads, usually for a malicious purpose. Spyware is installed secretly to record private information. A firewall controls what network data flows to and from your computer. Encryption software makes files unreadable without a password, e.g. on a stolen laptop.

4Simulation and modelling
Simulation and modelling
  1. Abstraction hides complexity and keeps only the key features.
  2. Simulations let us run experiments that cannot or should not be done in real life, such as raising Earth's temperature.
  3. Experts ask what if? questions, e.g. what if the bridge were twice as long?
  4. Problems: models include assumptions so answers may be wrong, and the real world is too complicated to include every factor.
