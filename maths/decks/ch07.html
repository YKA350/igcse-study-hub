7.2

Solving simultaneous equations by algebraic methods

Elimination

Elimination: add or subtract

Solve x + y = 9 and x − y = 3
Add2x = 12, so x = 6
Substitute6 + y = 9, y = 3
x = 6, y = 3
  1. Make the x (or y) numbers equal in both equations.
  2. Different signs: add. Same signs: subtract (DASS).
  3. Solve for the letter left.
  4. Substitute back to find the other.
Exam tipCheck in the other equation.

Scaling

When the numbers don't match

Solve 2x + 3y = 13 and x + y = 5
Multiply second by 22x + 2y = 10
Subtracty = 3
Substitutex + 3 = 5, x = 2
x = 2, y = 3
  1. Multiply one or both equations so a letter matches.
  2. Then add or subtract.
  3. Solve and substitute.
Exam tipMultiply every term, including the right side.

7.3

Solving simultaneous equations by a graphical method

Graphical

Where the lines cross

  1. Draw both lines.
  2. Find where they cross.
  3. Read the x and y of that point.
Solution

The crossing point is x = 2, y = 3 for y = x + 1 and y = 5 − x.

Substituteb = 3
pen $2, book $3

  2. Write one equation per fact.
  3. Solve, then answer in words.
