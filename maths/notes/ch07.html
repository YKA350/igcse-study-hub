1Simultaneous equations
Two equations, one answer

Meaning

x and y must work in both equations together.

Goal

Get rid of one letter, solve for the other.

Check

Put both numbers into both equations.

2Solving simultaneous equations by algebraic methods
Elimination: add or subtract
Solve x + y = 9 and x − y = 3
Add2x = 12, so x = 6
Substitute6 + y = 9, y = 3
x = 6, y = 3
  1. Make the x (or y) numbers equal in both equations.
  2. Different signs: add. Same signs: subtract (DASS).
  3. Solve for the letter left.
  4. Substitute back to find the other.
Exam tipCheck in the other equation.
When the numbers don't match
Solve 2x + 3y = 13 and x + y = 5
Multiply second by 22x + 2y = 10
Subtracty = 3
Substitutex + 3 = 5, x = 2
x = 2, y = 3
  1. Multiply one or both equations so a letter matches.
  2. Then add or subtract.
  3. Solve and substitute.
Exam tipMultiply every term, including the right side.
3Solving simultaneous equations by a graphical method
Where the lines cross
  1. Draw both lines.
  2. Find where they cross.
  3. Read the x and y of that point.
Solution

The crossing point is x = 2, y = 3 for y = x + 1 and y = 5 − x.

4Setting up and solving problems using simultaneous equations
From a story to equations
2 pens and 1 book cost $7. 1 pen and 1 book cost $5. Find each price.
Equations2p + b = 7 and p + b = 5
Subtractp = 2
Substituteb = 3
pen $2, book $3
  1. Choose letters for the two unknowns.
  2. Write one equation per fact.
  3. Solve, then answer in words.
Exam tipAlways write the final answer with units.
